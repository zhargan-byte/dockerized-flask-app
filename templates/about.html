About the project

Designed to make container fundamentals easy to see.

This application connects a concise Python backend, an accessible frontend, and a repeatable Docker runtime without hiding the important ideas behind unnecessary complexity.

01

Application layer

Flask maps URLs to Python functions, renders Jinja templates, serves static assets, and returns JSON for automated health monitoring.

create_app() → route → response
02

Runtime layer

Gunicorn runs multiple worker processes and provides a production WSGI server in place of Flask's development-only server.

gunicorn app:app
03

Container layer

Docker packages the exact Python runtime, dependencies, application code, and startup command into one portable image.

docker build -t flask-app .

Engineering principles

Simple, observable, and portable.

  • App factory supports isolated testing
  • JSON health endpoint enables monitoring
  • Non-root runtime reduces container risk
  • Responsive UI works across screen sizes
